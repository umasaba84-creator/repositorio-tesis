Estrategia Bibliográfica & Integración API

Cadenas de Búsqueda Recomendadas

1. Español (Enfoque Latinoamericano / LA Referencia): ("Seguridad Nacional" OR "Defensa Multidimensional") AND ("Inteligencia Artificial" OR "Ciberseguridad" OR "Prospectiva")
2. Inglés (Enfoque Global / NDLTD & OATD): ("National Security" OR "Geopolitics") AND ("Artificial Intelligence" OR "Cybersecurity" OR "Predictive Analytics") AND ("doctoral dissertation" OR "master thesis")
3. Híbrida (Prospectiva & Geoeconomía): ("Prospectiva" OR "Escenarios Futuros") AND ("Economía de la Defensa" OR "Recursos Estratégicos") AND NOT "Comercio Minorista"

Instrucciones para Conexión API / Backend

Para conectar esta interfaz web con un backend en vivo, consume servicios REST como OpenAlex API o Crossref API aplicando filtros por tipo de trabajo (type:dissertation).

// Ejemplo Fetch REST API OpenAlex
const url = 'https://api.openalex.org/works?filter=type:dissertation,title.search:cybersecurity';
const response = await fetch(url);
const data = await response.json();
